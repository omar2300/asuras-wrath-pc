# Asura's Wrath - PC version

The PC version of Asura's Wrath (a recompilation of the Xbox 360 game).

## Getting it

1. Download **AsurasWrath.exe** from the [latest release](https://github.com/omar2300/asuras-wrath-pc/releases/latest).
2. Put it in an **empty folder** with about 10 GB free (for example `D:\Games\Asura's Wrath`) and start it.
   Windows may warn that it does not know the program: *More info* > *Run anyway*.
3. It downloads the PC version's program files (1.6 GB), then installs the game from **your own copy**
   (Xbox 360 disc image; title update and DLC optional, also later).

**No game files are included or downloaded** - you need your own copy of the game.

Needs Windows 10 / 11, a processor with AVX2 and a DirectX 12 or Vulkan graphics card.
Installed copies check for new versions when they start and update themselves.
